# Account Settings & Preferences

Location: **Settings** tab — "Manage your profile, security and preferences."

## Profile information
Customers can update:
- **Name**
- **Email**
- **Phone**
- **Address**

Changes are saved via the profile update form on the Settings page.

## Preferences
- **Preferred Currency** — selectable via a standard dropdown (ComboBox).
- **Primary Branch Location** — selectable via a searchable dropdown (ComboBox),
  letting the customer pick their home branch by typing to filter.
- **Notification channels** — a multi-select preference between **Email
  Notifications**, **SMS Notifications**, and **Push Notifications** (customers may
  select more than one).

These preferences are saved to the customer's profile and restored automatically on
next login.

## Appearance
A **light/dark theme toggle** is available; the choice is remembered across
sessions.

## Notifications panel
The bell icon in the top header opens a notifications panel showing recent account
alerts (e.g. large transactions, security alerts). Customers can mark all as read.

## Assistant guidance
Route requests like "change my phone number," "switch to dark mode," "I want SMS
alerts instead of email," or "change my branch" to the Settings tab.
